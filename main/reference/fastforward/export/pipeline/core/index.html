    core

    Internal stage-based pipeline primitives for export pipeline composition.

    This module provides lightweight infrastructure used to compose and execute ordered export stages with dependency resolution and optional stage-to-stage evaluation.

    insert_stage_after(target, stage_fn, name, *, capture_stage_output=False) #

    Insert a new stage so that it executes immediately after target.

    The new stage depends on target. Every existing stage that previously depended on target is rewired to depend on the new stage instead, so downstream stages observe the new stage's output rather than target's.

    For a side-branch stage that depends on target without displacing target's existing dependents, use register_stage followed by add_dependency instead.

    insert_stage_before(target, stage_fn, name, *, depends_on=None, capture_stage_output=False) #

    Insert a new stage so that it executes immediately before target.

    By default the new stage inherits target's current dependencies and target is rewired to depend on the new stage instead, splicing it into the chain. Pass depends_on to set the new stage's dependencies explicitly; in that case target's dependencies are left untouched and the new stage is wired in only via the names you provide.

    replace_stage(target, stage_fn, name=None, *, capture_stage_output=None) #

    Replace an existing stage in place, preserving its position in the graph.

    The replacement inherits target's dependencies, and every existing stage that depended on target is rewired to depend on the replacement. If target was a result-capture stage or an evaluation stage, the replacement takes its place in those collections too.

    Parameters:

    Name Type Description Default
    target str

    Name of the stage to replace.

    		 required
    stage_fn Callable[..., Any]

    New stage callable.

    		 required
    name str | None

    Optional new name. Defaults to target's name (drop-in swap).

    		 None
    capture_stage_output bool | None

    Whether the replacement should capture its output. None (default) inherits the target's setting.

    		 None
